## deliberate, contract-mandated divergences (the counter must avoid them)

1. `--disable-compose` absent: the contract requires the tool to refuse with
   exit 2, while the judge still prints the Compose section. Every judged
   invocation must pass `--disable-compose`.
2. `--keysym` absent: same refusal rule; the judge would interpret ARG as a
   character/code point first (out of contract).
3. `--keymap FILE` (space separated) is *not* a file argument for the judge:
   how-to-type declares `--keymap` with an **optional** argument
   (`tools/how-to-type.c`, `{"keymap", optional_argument, 0, OPT_KEYMAP}`), so
   getopt leaves it NULL and the FILE becomes a positional; with
   `--keymap FILE --disable-compose --keysym ARG` the judge exits 2 with
   "missing positional parameter". The reference reproduces that (exit 2, empty
   stdout). **The frozen counter must use `--keymap=FILE`.**
4. `--keysym=ARG` → getopt rejects the argument → judge exit 2; reference exit 2.
5. A stdin keymap (`--keymap` with no `=`, one positional) and an RMLVO compile
   are out of contract; the reference refuses with exit 2.
6. `--help`/`-h` prints the usage on stdout with exit 0 in both, but the usage
   line embeds `argv[0]`, so the two cannot be byte-identical there.
