## 6. Flags for the L1

- **Header count.** The claim says the header has 2659 `#define XKB_KEY_` lines. `grep -c 'define XKB_KEY_'` returns 2659,
  but 21 of those are inside the header's own doc comment; anchored `grep -cP '^\s*#\s*define\s+XKB_KEY_'` returns 2638. A
  C1 fixture or counter that greps the prefix will read 2659; one that parses definitions will read 2638.
- **Header sufficiency (corrected mid-run).** `S356`/`S358` first said the header cannot reproduce lookup order or canonical
  names; checked with a script over the two pins, it can: each value maps to the **first** `#define XKB_KEY_<name>` in file
  order and that reproduces `ks_tables.h`'s `keysym_to_name[]` exactly (2505 values, 0 mismatches; last-define rule flips
  120). `name_to_keysym[]` equals the header's 2638 names value-for-value. Both rows and the gate line were rewritten; the
  sibling C1 seat's 10,613-ARG parity sweep and 344-row second-keymap run agree.
- **S359 carries the layout section** (`:462-474`: "The first layout defined in the input section will be the one used for
  binds by default", the `us,ua` example, and the `resolve_binds_by_sym = 1` paragraph at `:468-470`), so the 0.56.x
  keyboard-layouts text does not need a separate row off the current wiki tree.
- **`--keymap` is `optional_argument`** (`tools/how-to-type.c:171`): only `--keymap=FILE` binds the file; `--keymap FILE`
  leaves FILE as the positional keysym argument. C1 fixtures should use the `=` form the contract already writes.
- **Wiki pin.** `hyprwm/hyprland-wiki` has no tags; the pin is the last content commit before the 0.56.2 release
  (`d5f07c60`, 2026-08-05T13:16:48Z). `content/Configuring/Basics/Binds.md` is byte-identical at `5e26bcc1`
  (2026-08-05T19:54Z, 6 h later): sha256 `3d8a2a6832da59304697aff1a3c72a35e02ea43737035c99b841d0854b17d628` both.
- **Already held, cited not registered.** `ConfigValues.cpp` `:278` default lies inside S318's `:271-279`; `IKeyboard.cpp`
  is S319. If the C2 entry relies on `IKeyboard.cpp:376-385` for the zero-modifier sym state, that is a scope widening of
  S319 that only the L1 can make.
- **Platform shape.** `hyprctl binds -j` has no `ignore_mods` field in this build (the flag is parsed but not serialized);
  zero binds on this host use it, so the flag's host evidence is code-only (S353 `:1525`) on this host.
