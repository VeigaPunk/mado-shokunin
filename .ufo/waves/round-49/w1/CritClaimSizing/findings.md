## C1 — `tools/mado-keysym.py`

C1 claim is arbitrary serialized keymap + keysym -> exact pinned judge stdout/rc, Python stdlib only, no process/socket/write (claims.md:14–24). Draft is materially stronger than a fixture-only checker: it compiles keymaps at count time and invokes the pinned judge (C1 draft:25–49, 393–441); runs nonce cases; uses a restricted mount set without libxkbcommon (50–68, 464–515); and traces tool execution (37–49, 516–564). **Universal clause sizing:** C1 states an unbounded behavioral contract (any compiled XKB keymap/keysym), while f/g are finite (fixture count and GEN=60; fixed pools at C1:145–149, 268–298, 567–588). The report must say this is a sample-based discriminator, not proof of all RMLVO/keysym pairs. No finite fixture suite rules out a deliberately comprehensive table; only a non-finite domain restriction or semantic implementation review could. Biggest affordable improvement: add hidden nonce-derived RMLVO/keysym cross-product probes, including Unicode `U...` forms and aliases, and vary path/argv ordering. The C1 behavior probe confirmed no stdout for invalid keysyms, exact output for slash, and rc 2 for invalid names; it did not validate a candidate tool.
