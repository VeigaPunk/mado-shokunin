why: Parser.cpp:139-141 stores (0,0) for '0x0'; Monitor.cpp:773 reads that as PREFERRED, so Hyprland picks the preferred mode, not a 0x0 mode. The tool compares width==0 and height==0 and says DIFFER.

model rules: [["DP-1", false, 0, 0, 60.0, 0, 0, 1.0, 0, ""]]
model assignment: [["DP-1", 1]]
tool| MADO_MON_RULE: n=1 sel="DP-1" mode=0x0@60.00 pos=0x0 scale=1.0000 transform=0 mirror=- disabled=false
tool| MADO_MON_OUTPUT: name="DP-1" rule=1 differ=mode verdict=DIFFER
tool| MADO_MONITORS: lines=1 rules=1 v2=0 unsupported=0 badrules=0 outputs=1 matched=1 unruled=0 agree=0 differ=1 disabled=0 verdict=DIFFER
