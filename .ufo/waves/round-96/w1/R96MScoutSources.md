### D-2 -- The accepted word-size set is `{0,1,2,4}`, not `{1,2,4}`; the modulo check is guarded by `word_size > 1`

The receipt's S524 row says *"word size 1/2/4"*, and the shared contract says
*"(1|2|4 only)"*. The C says otherwise, at `xdgmimemagic.c:440-443`:

```c
if (matchlet->word_size != 0 &&
    matchlet->word_size != 1 &&
    matchlet->word_size != 2 &&
    matchlet->word_size != 4)
  /* parse error */
```

The set is **{0, 1, 2, 4}** -- `word_size 0` is **accepted**. And the whole swap plus
modulo block sits behind `xdgmimemagic.c:471` `if (matchlet->word_size > 1) {`, so
with word size 0 or 1 there is **no swap and no modulo check** -- `value_length %
word_size` is never evaluated (for 0 that would be a division by zero).

Measured against the r95 oracle (text-mode fixtures):

| fixture | answer |
|---|---|
| `>0=\x00\x02AB~0`, data `AB` | `text/x-ws0b` -- accepted |
| `>0=\x00\x03ABC~0`, data `ABC` | `text/x-ws0odd` -- accepted, **odd length, no modulo check** |
| `>0=\x00\x03ABC~2`, data `ABC` | `text/plain` -- rejected (3 % 2 != 0), section dropped |
| `~3`, `~5` | rejected, section dropped |

**Impact.** A model that accepts only `{1,2,4}` rejects a legal `~0` section the
oracle matches. A model that applies the modulo check unconditionally divides by
zero. The **C1 draft in `build/` already states the correct rule** (*"only 0, 1, 2, 4
pass :440-443; the C treats 0 like 1"*) and matches the oracle on every fixture
tested -- so the defect is in the receipt/contract wording, not in the candidate.

### D-3 -- Cache mode requires a **loadable** `mime.cache`, not merely a present one

Receipt/contract wording: *"a reachable `mime.cache` means cache mode"*; *"a case
that holds a `mime.cache` is a cache-mode refusal case"*. The C's rule is stricter
and the receipt's S505 citation never states it:

- `xdgmimecache.c:63-65` -- `MAJOR_VERSION 1`, `MINOR_VERSION_MIN 1`, `MINOR_VERSION_MAX 2`
- `xdgmimecache.c:128` -- `if (fstat (fd, &st) < 0 || st.st_size < 40) goto done;`
- `xdgmimecache.c:137-139` -- version must be major 1 and minor in 1..2
- `xdgmime.c:137-154` -- a cache that *loads* is added to `_caches` and that dir's text files are skipped
- `xdgmime.c:180-190` -- otherwise `DIR/mime/magic` is read as text
- `xdgmime.c:532-535` -- if **any** cache loaded -> cache reader only; else the text magic reader

Measured:

| `mime.cache` in the dir | mode | answer |
|---|---|---|
| 0 bytes | **text** | `text/x/t` (from the magic file) |
| 14 bytes garbage | **text** | `text/x/t` |
| 39 bytes | **text** | `text/x/t` |
| 40 bytes, version 1.1 | **cache** | cache-mode |
| 40 bytes, bad major version | **text** | `text/x/t` |
| the real `/usr/share/mime/mime.cache` | **cache** | cache-mode |

**Impact.** A case whose fixture holds a *short or corrupt* `mime.cache` is answered
by the oracle in **text mode**, but the contract's case rule would label it
`["UNSUPPORTED",null]`. The rule must read *"holds a **loadable** `mime.cache`
(>= 40 bytes **and** version 1.1/1.2)"*. This matters directly for the frozen case
file's `mode` class.

## 5. Oracle measurements (the behaviour the model must reproduce)

Oracle = `.ufo/waves/round-95/controls/mimesniff-oracle-r95.c`, sha256
`99df35f8...4d124a`, built in scratch with
`cc -O0 -o "$S/oracle" <src> $(pkg-config --cflags --libs gio-2.0)`, run as
`env -i LC_ALL=C HOME=<case>/h XDG_DATA_DIRS=<case>/d1 "$S/oracle" <0|=NAME> <file>`.

**M-1 byte swap -- CONFIRMED.** `>0=\x00\x02\x01\x02~2` matches data `02 01` and
not `01 02`; with `~1` it matches `01 02`. Word sizes 2 and 4 byte-swap the value
(and the mask) per word at parse time.

*Provenance gap in the receipt:* the swap is under `#if LITTLE_ENDIAN` (473, 482).
**`LITTLE_ENDIAN` is not a glib build flag** -- the upstream `meson.build` defines
only `g_byte_order`/`G_LITTLE_ENDIAN` for the public `glibconfig.h`, and
`gio/xdgmime/meson.build` adds only `-DHAVE_CONFIG_H` and `-DXDG_PREFIX`. It comes
from **glibc's `<endian.h>`** (`bits/endian.h` under `__USE_MISC`), which
`xdgmimemagic.c` reaches through its own include set -- I compiled that include set
standalone and `LITTLE_ENDIAN` is defined. Arch's `PKGBUILD` for glib2 2.90.1-1
builds with meson, adds no `-DLITTLE_ENDIAN`, and its two downstream patches touch
schemas and terminal names only. The receipt's *"on this LE host 2/4 values and masks
are byte-swapped"* is **true for this host**, but the located quote it offers
(421-450) is the modulo check, not the swap, and the `LITTLE_ENDIAN` guard is not
cited at all. The corpus row should cite **471-497** and name the guard.

**M-2 word sizes** -- see D-2.
**M-3 cache-mode trigger** -- see D-3. Also: a valid cache in dir A makes the whole
answer come from the cache; a text magic file in dir B is then ignored.
**M-4 error recovery** -- a bad matchlet line drops its whole section and the file
continues; a bad header (no `]`) drops the section *and* consumes the next line; a
bad header followed by a junk line then a good section -> the good section survives
(the junk line absorbs the skip).
**M-5 insert / lookup order** -- priorities `[10, 90]` -> the 90 section wins (file
order irrelevant); equal priorities -> earlier-in-file wins; two directories at equal
priority -> the earlier directory wins (one global list, XDG_DATA_DIRS order).
**M-6 tree / indent** -- indent 0 is top level; a *first* matchlet at indent 1 -> the
section never holds; indent 0 -> indent 2 (level skipped) -> the section never holds;
a parent that holds with a child that does not -> the whole section fails; a child
that holds -> the parent holds.
**M-7 data path** -- `len 0` -> `application/x-zerosize` (priority 100); no magic match
-> the 128-byte fallback; with a name type present, `sniffed_prio >= 80` wins
outright (80 and 90 win, 50 and 79 do not), else the first name type that is a
subclass of the sniffed type, else the first name type, uncertain.
**M-8 header gate** -- a magic file whose first 12 bytes are not exactly
`MIME-Magic\0\n` contributes no magic; a file shorter than 12 bytes likewise.

**C1 draft cross-check.** `build/mado-mimetext.c1.py` copied read-only into scratch
with its sibling `tools/mado-mimeglob.py`; compared against the oracle on **116
fixtures** this seat constructed covering M-1...M-8, in both `name=NULL` and
`name=f.txt` modes: **116 compared, 0 mismatches.** (The four fixtures the draft
refuses are the intended cache-mode refusals, excluded -- see D-3.)

   either make the two multi-line quotes verbatim spans (525-526, 571-574) or drop
   them as single-line quotes.
4. Either state the spec-page extraction basis or switch the S525 citations to
   raw-HTML lines (387, 391, 394, 398, 403, 421, 426, 429).
5. Replace the fetch-dir layout claim with the measurements actually on disk, and

Items 1 and 2 are the ones that can change answers; the rest are citation accuracy.
