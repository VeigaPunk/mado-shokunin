**Divergence to record in the entry (measured against the C, not the spec):** the spec says only the bad
*line* is ignored; the C (`:283-300` + `:749-782`) drops the whole *section* (parse_error skips to the next
newline and returns to SECTION; a following matchlet line is then an ERROR again). The tool models the C
because the oracle is the installed library. A second divergence: the spec says "Higher priority entries come
first" in the file; the C re-sorts (`insert_match`) so file order is irrelevant except for equal priorities.
