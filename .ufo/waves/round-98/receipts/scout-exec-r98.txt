## headline measurements (all reproduced in the report)
- iteration rule: Exec=probe %f + 3 files -> 3 launches (one file each); %F + 3 -> 1 launch;
  %f %f + 3 -> 2 launches; %f %F + 3 -> 1 launch; no field code + 3 -> 3 launches.
- % walk: the byte after % is consumed as the selector: "100% done" -> "100done", "a%1b" -> "ab".
- %F with a non-local URI: the URI is consumed and DROPPED (no text, no separator).
- separator: emitted only after a non-NULL expansion; "x%F" -> "x/abs/.../a.txt" (concatenated).
- %u with a local file -> the PATH (not file://); with X-GIO-NoFuse=true -> the URI.
- %i: Icon=foo.png -> "foo" (extension stripped); Icon= (empty) -> "--icon" + "".
- %c: Name is a LOCALE string (Name[en_US] wins under LC_ALL=en_US.UTF-8).
- %k: the CANONICALIZED absolute desktop path.
- no-substitution rule fires when the URI-list HEAD POINTER is unchanged, so a non-consuming
  macro (%c/%i/%k/%m/%z) still triggers it: Exec=probe %c + 1 file -> [probe, 'Probe App', file].
- '#' at a token start is a comment: "probe keep # drop" -> [probe, 'keep'].
- EXEC ORACLE DEFECT (quiescence): the 200 ms quiescence reader stopped at 0.22 s having seen
  1 record while the file eventually held 2 -> TRUNCATED LABEL, 4/4 trials. gio launch returns
  at 0.003 s, before its child writes at 1.0 s.
- EXEC ORACLE DEFECT (order): the shared append file records COMPLETION order, not spawn order;
  with the first-spawned child delayed 1 s the file order is inverted, 3/3 trials (and 1/20 under
  8x CPU load without a delay).
- verified fixes: one atomic write per record (25/25 clean, vs 1/20 torn for the multi-printf
  form); per-child files (the file count equals the launch count exactly: 3, 3, 1, 2).
