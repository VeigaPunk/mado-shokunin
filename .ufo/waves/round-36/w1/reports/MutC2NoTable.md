# MutC2NoTable — mutation-tester seat, mado round 36 wave 1

Task: write a `/tmp` variant of C2 that keeps the computed tip rule and the
tip-line test but drops the document-table parse (rows re-derived from the spec,
as round 35 did). Run it against `c2-blob-corrupt` and `c2-blob-row-deleted`;
report the two verdicts — this isolates the cost of parsing the document's own
table.

## Instrument

`/tmp/mutc2notable-c2.py` (sha256
`b1b4c850f86132a5bab07068c5ee334b04d33351d49d6e1f4d952be3d68a4d7e`).

Diff vs `quality/counters/c2-ledger.py` (`92db777e7573411835b8686f86520e1f891e8f5e44d6a9c3c18fe8c488193833`):
only three hunks are behavioral — `ROW` regex dropped; the table-parse block
(`for m in rows: … blob drift … row set differs`) replaced by a loop over
`spec["frozen_blobs"]` that requires each path to resolve at the computed tip
(`git rev-parse <tip>:<path>` succeeds, round-35 style, never comparing against
the document); output tag `PRED-C2-r36-v1+mut-no-table` (verdict token protocol
unchanged). The predicate/target drift guard, clause scan, superseded-ledger
naming check, computed-tip rule and tip-line test are verbatim from the frozen
counter. `PREDICATE` string unchanged → the frozen `frozen.json` loads.

## Verdict

| Control | Mutation applied | Pristine counter | No-table variant |
|---|---|---|---|
| `c2-blob-corrupt` | row 1 blob id → `0…0` | killed (`TARGET_MISSED`) | **SURVIVES** (`TARGET_MET`) |
| `c2-blob-row-deleted` | last table row deleted | killed (`TARGET_MISSED`) | **SURVIVES** (`TARGET_MET`) |

Both assigned mutants **survive** the no-table variant. The table parse is
therefore the *only* observable that kills these two mutations: with rows
re-derived from the spec, a corrupted row id or a deleted row changes nothing the
counter reads. The computed-tip rule + tip-line test remain load-bearing for
`c2-tip-stale` (still killed) and are unaffected by the isolation. This is the
measured cost of the document-table parse: it is exactly what turns the blob
ledger's own rows into checked evidence rather than decorative prose.
