### 2.4 Reference core (decision-bearing code, verbatim from the prototype)

```python
def norm_path(token):                      # spelling-blind path, case preserved for tree lookup
    text = token.strip(EMPHASIS)
    text = text.split("#", 1)[0]
    text = ANCHOR.sub("", text)            # any :suffix  -> P07
    text = re.sub(r"/{2,}", "/", text.replace("\\", "/"))   # P19
    text = re.sub(r"^(\./)+", "", text).lstrip("/")         # P05, P20
    return text.strip(TRAIL).strip(EMPHASIS)               # P06 trailing ')'

def identity(token):
    return norm_path(token).casefold()      # P21, P03, P04

def path_tokens(path):                      # H4n: hyphen/underscore parts are path words too
    stem = os.path.splitext(os.path.basename(path))[0]
    return set(WORD.findall(" ".join(re.split(r"[-_.]+", stem.casefold()))))

def template_of(desc):
    return re.sub(r"\s+", " ", re.sub(r"\d+", "#", desc.strip(EMPHASIS).casefold())).strip(" .;:")

def distinctive_token(tree, pop, path, desc):   # containment df, early abort
    blob = tree.blob(path).lower()
    for token in sorted(set(described_tokens(desc))):
        if token in path_tokens(path):
            continue
        needle = token.encode("utf-8", "surrogateescape")
        if needle not in blob:
            continue
        seen = 1
        for other in pop:
            if other != path and needle in tree.blob(other).lower():
                seen += 1
                if seen > MAX_TOKEN_DF:
                    break
        if seen <= MAX_TOKEN_DF:
            return token
    return None
```

`measure(tree, ledger_text)` is pure over a two-method tree abstraction (`paths()`,
`mode(p)`, `blob(p)`), so `GitTree` (a `--shared --no-checkout` scratch clone) and `DictTree`
(the selftest) exercise one code path. Fields print in a fixed order and the verdict is
`TARGET_MET` only when `population > 0`, `ledger_rows == population`, and every defect field is
0; exit 0/1/2 = met/missed/setup error.

### 3.3 Counter `quality/counters/c2-r53-dispatch-repair.py` — clauses

The r52 counter's failure was shape and binding, not arithmetic: it expected `| P## | S### | …`
while the entry is `| P## | Proposition | S### | …` → `props=0` (`Attack07` T1), and its quote
binding was file-wide, so fabricated quotes at real pins passed (T6). Clauses:

| Field | Rule |
|---|---|
| table | the proposition table is located by **header names** (`ID`, `Proposition`, `Source row`, `Pin:anchor`, `Quote`, `Scope`, `Why it supports`, `Replaces`), never by position; a `#` heading resets the remembered header so a later table is not read with these columns; row width must equal the header width |
| `props`/`dup_id` | ≥ 3 rows on the real run (1 in the selftest), ids unique and `^(P|C)\d\d$` |
| `bad_source` | each row names exactly one `S###` that exists exactly once in `corpus/SOURCES.md` (a blank line does **not** end the registry: S370–S373 sit in a separate block after one) |
| `bad_pin` | pin is one **contiguous** `file:start[-end]`; file resolves in a `--fetch-dir`; span inside the file; span ≤ 40 lines |
| `bad_quote` | non-empty, not a placeholder, ≤ 25 whitespace words |
| `quote_not_in_span` | the whitespace-collapsed quote is a substring of the collapsed **span** (this is what makes a pin bind a quote) |
| `missing_scope`/`bad_scope` | a `Scope` column is required; the declared value's last `::`-segment must equal the enclosing function computed from the pinned bytes at the span start (column-0 declaration line, string literals and `//` comments stripped); a header-file pin with no enclosing function requires empty or `-` |
| `containment_unbound` | if the proposition says `inside`/`within`, the span must itself contain the `for (`/`while (`/`if (` opener governing the quoted line |
| `bad_why` | rationale non-empty, not a placeholder |

### 3.5 Residuals

1. **Prose truth is not scored.** A row can quote a real span inside the right function and
   still overstate it; that is the frozen claim's own boundary ("independent reviewer checks
   source truth"). The counter's job is to make the reviewer's job possible: without a span
   substring match, `Attack07` T6 showed a reviewer cannot tell fabricated evidence from real.
2. **Ordering/containment wording beyond `inside`/`within`** is not checked (e.g. "before",
   "then"). A second clause would need a claim grammar; not worth it at this size.
3. **The source row's own anchor range is not enforced** (a pin may lie outside the `:a-b`
   recorded in `SOURCES.md`). Deliberate: the row anchor spells `ConfigActions.cpp:1530-1616`
   while the pinned file is `Hyprland-ConfigActions.cpp`, so a basename comparison would need a
   suffix rule. Cheap follow-up if L1 wants it: suffix-match the basename and require
   `anchor_start ≤ pin_start` and `pin_end ≤ anchor_end`.
4. `enclosing()` is a column-0 declaration scan (correct for these files, which declare
   functions at column 0); a multi-line or continuation-style declaration elsewhere would need
   the parser extended. Bounded by `MAX_SPAN` and the declared pin set.
