## 2. C1 — the minimal corrected contract

The contract below is the smallest set of clauses that (a) accepts the 82-row production ledger
unchanged, (b) rejects every forgery family the r52 wave actually demonstrated, (c) is decidable
from `--rev` bytes plus a fixture file, and (d) cannot be satisfied by a second, weaker program.
Every clause is falsifiable; none claims entailment.

**S — single authority and scratch discipline.** One committed program at one path; its sha256 is
recorded in the registration/freeze and on every receipt. The counter clones `--rev` into
`--work` (`git clone --shared --no-checkout`, checkout detached, assert `clone HEAD == rev` and
`clone toplevel == clone`) and reads only `git show <rev>:<path>`; it never reads the working
tree. `--work` must realpath **outside** the scored repo and outside `/tmp`, `/var/tmp`,
`/dev/shm` and the home root, refused before any directory is created — the same rule the
committed checker already enforces (`quality/check-tool-ledger.py:414-427,753-757`). No second
program participates in the verdict.

**P — population, derived not declared.** `P = git ls-tree -r --name-only <rev>` filtered by the
ledger's own rule: every `tools/` file plus direct-child `.py` under `quality/` and
`quality/counters/`, excluding `__pycache__`/`.pyc`/`.pyo` (`c1-r51-ledger.py:133-153`). At base
`|P| = 82`; the 82 ledger paths are set-equal to it. The check is identity set equality, not
count equality; a duplicate row is `dup`, a non-population row is `dangling`, a population path
without a row is `uncovered`, and all three must be zero while `ledger_rows == |P|`.

**R — row grammar.** Exactly the ledger's three cells (`path | description | pointer`), parsed
with fenced blocks skipped. A row with a different cell count is `malformed`, counted and
reported **separately** — never silently dropped, because the frozen no-work control may itself
be malformed and the red receipt must still name the intended defect classes.

**N — pointer accountability.** Normalise the pointer token (strip `./`, collapse `//`, strip a
`:line` suffix, reject absolute/`~`/`$` paths), resolve it with `git ls-tree` at `rev`, and
require all of:
1. the resolved entry is a regular blob (mode `100644`/`100755`); a symlink (mode `120000`) is
   not a document and is refused;
2. the resolved path is **not** `quality/tool-ledger.md`, **not** the row's own path, and **not**
   any population path (a peer instrument is not accountable for its sibling);
3. the resolved path belongs to the ledger's declared pointer classes — `PROVINCE.md`,
   `SCORECARD.md`, `corpus/QUALITY.md`, `corpus/lessons/round-N*.md`, `corpus/knowledge/*.md`,
   `.ufo/waves/round-N/registration.md` (`quality/tool-ledger.md:22-27`);
4. its bytes name the row's basename as a **name** (word-boundary regex), not as a fragment.

Measured at base: 82/82 rows satisfy N with zero self-pointers and zero pointers outside the
allowlist, so the tightening costs no production row:

### 4.2 Counter clauses (one committed program, digest recorded)

a. **Parse by header name**, not column position: `id`, claim/proposition, source row,
   pin/anchor, quote, rationale; tolerate a trailing parenthetical; reject a header that maps two
   roles to one column. Backtick-aware cell splitting with `\|` unescaping.
b. **Pin resolution**: exactly one fetch root; basename must resolve under it; the file's sha256
   must equal the digest recorded by the source row (`.ufo/waves/round-52/fetch/SHA256SUMS`) —
   basename search across the wave tree is forbidden (r52 carried 9 `Hyprland-*` pin files — the
   four fetch pins, four byte-identical duplicates and one fixture copy — so a basename index that
   drops collisions silently loses P07).
c. **Anchor grammar**: `line`, `range`, and comma multi-span are parsed explicitly; an
   unparsable anchor is a failure, never a truncated match. The quote must bind inside the
   **contiguous** cited span; spans are never concatenated for a binding test.
d. **Quote binding**: whitespace-collapsed containment in the cited span, `3..25` words, raw
   binding reported alongside (`quotes_raw=N/M`); fabricated and spliced quotes fail.
e. **Scope binding** (new, and the clause that catches P17/P18 structurally): if the claim's
   first backticked token names a function **defined in the pin file**, it must be the function
   enclosing the anchor start (nearest preceding definition at or before the anchor); and a claim
   asserting `inside the scan|loop` must have its anchor inside a loop body. Measured to flag
   exactly P17 and P18 on the old entry and nothing on the corrected fixture.
f. **Supersession**: every `superseded` id remains present and names replacement ids and a
   reason; superseded rows are excluded from the admitted set; replacements must bind (b–e) and
   must not duplicate an admitted claim or quote (equality **or** substring containment).
g. **Coverage**: every admitted proposition id is drawn on outside the map (or the freeze
   explicitly adopts row-granularity — the draft's clause (e) is a self-imposed strengthening the
   frozen text does not state); every source row exists at `rev`, is referenced, and the index
   row is unique; at least two distinct rows.
h. **Discrimination, frozen before data**: old entry bytes at the base revision → `TARGET_MISSED`;
   corrected bytes → `TARGET_MET`; mutants, each `TARGET_MISSED` with the named clause:
   fabricated quote at a real pin; splice across a conditional; subject swap (P17 shape);
