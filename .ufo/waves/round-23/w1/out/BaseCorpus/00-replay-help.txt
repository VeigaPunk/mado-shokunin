usage: replay.py [-h] --tool TOOL
                 --mode {oracle,resource-api,resource-cli,corpus}
                 [--before-tool BEFORE_TOOL]

Run one explicit round-21 measurement command and emit its raw receipt. The
selected harnesses parse scanner fixtures; this driver does not execute
fixture contents or change any harness limits.

options:
  -h, --help            show this help message and exit
  --tool TOOL           selected scanner file
  --mode {oracle,resource-api,resource-cli,corpus}
  --before-tool BEFORE_TOOL
                        required before-scanner for corpus comparison
