## 5. Defects and ambiguities

- **D1 (medium, contract-mandated path writes /tmp).** The harm watch `bash tools/mado-verify.sh --selftest` (registration harm watch; claims-frozen.md "Harm watch") runs `selftest()` which does `mktemp -d /tmp/w5-mado-m52-selftest.XXXXXX` (base 13f0acbe, line 418). The tool has zero TMPDIR references and no scratch argument, so neither `TMPDIR=` nor `--work` can redirect it. The directory is removed on success (line 1875) and kept on failure, named in `fixtures kept:`. Its size was **not measured** (I did not run the selftest). A contract-following harm-watch run therefore writes under /tmp. Options for L1: disclose as a §7.4 exception or amend the tool next round.
- **D2 (low).** `scripts/sources-census.sh` selftest: `mktemp -d "${TMPDIR:-/tmp}/..."` falls back to /tmp when TMPDIR is unset (line 164). Only the selftest; the harm-watch `validate` path does not create temp dirs. Violates §7.1 "never rely on an inherited TMPDIR" if the selftest is ever run without TMPDIR.
- **D3 (low, adjacent).** base `quality/counter-selftest.py:482` uses `tempfile.gettempdir()` when no scratch argument is given. Not a round-56 predicate; wave-2 seats must not use it without `--scratch`.
- **D4 (medium, rule overstated).** lane-addendum §7.5 says the driver deletes any entry under `/tmp`, `/var/tmp`, `$HYAKU_SCRATCH` idle 45 min. `disk-guard.sh` `cmd_sweep` returns "ok ... below soft" without deleting when `pct < SOFT_PCT` and neither `--all` nor `--emergency` (lines 619-621). At 21 % /tmp, `/tmp/verif-kasegi-r42` (25.4G, idle 480 min) and the round-56 leftovers below are **not** reaped now. Reaping happens only under pressure, at `purge-lane` (whole `mado-r56` at round advance, live-process check only), or `--all` at run end. The /tmp "not citable" rule is the only enforcement while the gate is green.
- **D5 (low, ambiguity in frozen text).** registration.md:11-12 says "honour `--work DIR` (created when missing ...; the counter itself writes nothing)". Creating `--work` is a write; the wave spec (not frozen) also requires a counter `--selftest` that builds a scratch repo under `--work`. Resolution proposed: the main path writes nothing, `--work` is created by the harness, `--selftest` is outside the predicate. Not a predicate defect.
- **D6 (medium for wave 2, ambiguity).** Registration §C1/§C2/§C3 say harnesses export or build "into a scratch dir" / "scratch repo" without naming it. A literal implementation using Python `tempfile.mkdtemp()` (no `dir=`) or the default TMPDIR writes under `/tmp`. Require `tempfile.mkdtemp(dir=work)` and `mktemp -d -p "$work"` explicitly; the harness parent process must not rely on TMPDIR either.
- **D7 (low, layout dependency not stated).** `ctl/const-host.py` and `ctl/lookup-committed.py` resolve `Path(__file__).resolve().parent.parent / "fixtures/c2"`. The C2 export must therefore place `ctl/` at `<export>/ctl/` beside `<export>/fixtures/c2/`. A flat export makes `lookup-committed` pass 0/18 and the control fails as "controls=2/3", not as a scratch error. Recorded in the §4 layout.
- **D8 (low, §7.4 inapplicable).** `tools/mado-watchplan.py` takes no `--work` and rejects it as `usage`. Any `--selftest` it grows must write nothing (in memory) or use `tempfile.mkdtemp(dir=$TMPDIR)`; registration does not say which.
- **D9 (low, lane pollution).** wave-1 seats imported modules from their lane deliverable dirs, leaving git-ignored `__pycache__` in `.ufo/waves/round-56/w1/` (`R56ExecC3CounterA`, `R56ExecWatchplanHarness`, `R56ExecC1Harness`). Ignored by `.gitignore:3`, but still written inside the lane. Wave-2 seats: `python3 -I -B` or `PYTHONDONTWRITEBYTECODE=1`.
- **D10 (low, leftovers, not mine).** round-56-named leftovers under `/tmp` (14 entries, owners not verified, same uid): `mado-r56-census-before.txt` (21:01, pre-receipt draft without `rc=0`), `r56_coldread_c0.json` (3.0 MB), `r56-sources-at-freeze.md` (131 KB), `census-r56*.out`, `kama-r56-closure.json`, `mori-r56-closure-entry.json`, `r56seats.txt`, `r56rev_added.txt`, `r55r56-notes.txt`, `r56_c1_c0.txt`, `r56_noharm_c0.txt`. Not cited anywhere in this report and not deleted by me. L1 should delete or leave to the reaper and keep them out of every citation.
- **D11 (medium, round close).** `disk-guard.sh purge-lane mado 56` removes the entire `/fast/scratch/hyaku/mado-r56` at advance if no live process is inside. Any wave-2 receipt not copied into `.ufo/waves/round-56/w2/` is lost at round close.
- **D12 (low).** A seat with `cwd` at the fleet root (host guard) that computes for >45 min without writing, and holds no open fd in its scratch, is reapable under pressure (D4). Mitigation in §4 (cwd in `$S` or heartbeat).
