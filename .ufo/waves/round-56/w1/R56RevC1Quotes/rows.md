# R56RevC1Quotes — independent verification of c1 K and H rows

Scope: `frozen-tables.json` c1.k (30 rows) and c1.h (3 rows) checked against the pins in `.ufo/waves/round-56/fetch/` with a seat-written script (`verify_rows.py`, receipt in this directory). `freeze-verify.py` was not used.

## Checks run (all 33 rows)

- Substring: every frozen quote is a byte substring of its pin file at the stated 1-based line. 33/33 hold.
- Uniqueness: every quote occurs exactly once in its whole pin file and on exactly one line. 33/33.
- No `|`, no leading/trailing whitespace, no tab, no backslash in any quote. 33/33.
- sid mapping: each K row's `sid` equals `c1.rows[sid]` (the pin the row cites). 30/30. The sid set used by K rows is exactly S383..S390 = `c1.new_row_ids`.
- Pin hashes: all 12 pins match their frozen sha256 (8 Hyprland/man7 and 4 host). Each Hyprland pin, and the man7 page, is byte-identical to the upstream copy fetched during this seat (`raw.githubusercontent.com/hyprwm/Hyprland/efb50993780079460b0cbed1363e2166a2de1d9f/<path>`; man7 fetched live). Provenance of the pins is therefore confirmed for the eight sourced files; the host captures are not upstream and are not checked against upstream.
- Freeze commit `3423ae285676c2a10273000f4519163472b443db`: the 12 pin blobs in it equal the working-tree files. `corpus/knowledge/hyprland-config-autoreload-r56.md` is absent at that commit (expected: the scribe writes it in this wave); no proposition text exists yet, so the propositions below are this seat's own maximum readings of each single line, not a comparison with an entry.

Result: 33/33 rows pass every check above. Defects are not in the frozen quote bytes; they are in what a quote alone can support (below). Quote-level flags: **K07, K08, K24** (quote is a truncated expression; the full pin line changes the reading) and **K08 in particular** (quote alone asserts a false equality).
