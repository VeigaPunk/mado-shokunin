**100.** **A host-consequence model or claim about which state a compositor reads cites the source line that sets that state** — A model of what the host will do (which xkb state a key press is translated in, which config value a compositor reads at which moment, which modifier mask a matcher compares) states, per claim, the symbol it depends on and cites the line that **sets** that symbol — an assignment or an update/constructor call taking the symbol as its first argument — not a line that merely reads it; where the claim gives the symbol an attribute (`attr=modmask value=nonzero|zero`), the setters that exist in the traced source must support that value, and a state with no setter for the attribute, or setters that pin it to another value, is `VALUE_CONTRADICTED` and the claim is withdrawn or restated. The cited line's classification is the instrument's, never the author's. Check: `python3 -I quality/check-state-cite.py --claims <claims-file> --source <traced-source-dir>` prints one `STATE_CLAIM claim=<id> state=<sym> attr=<a> value=<v> cite=<file>:<line> line=SITE_SET|READ_ONLY_CITE|STATE_NOT_ON_LINE setters=<n> nonzero_setters=<n> verdict=OK|FAIL` per claim, `LOCATOR_UNRESOLVED`/`CLAIM_UNPARSED` per malformed line, and `CHECK100: claims=<n> set=<n> readonly=<n> unresolved=<n> contradicted=<n> verdict=OK|FAIL`, exit 1 on any non-OK line. **101.** **Every deliverable a seat or report declares exists at the cited revision** — A seat report declares its deliverables in one of the lane's two existing grammars — the `Report:` trailer the dispatch mandates, and one `- \`<path>\`` bullet per file under `## Deliverables` / `## Files written` / `Written:` — and every declared path resolves: seat-dir-relative first (`.ufo/waves/round-N/w1/<Seat>.md` declares against `.ufo/waves/round-N/w1/<Seat>/`), then as written, and the resolved path is proven with `test -f` before the report is committed and `git cat-file -e REV:path` at the revision being scored. A declaration whose path is absent is `ABSENT` whatever the prose says about it; with `--require-declaration` a report that declares nothing is `UNDECLARED`, which the round reads as a seat-report defect rather than a clean report. Free-text path tokens are out of scope by measurement, not by taste.
