## 4. The two false passes

### B1 — `writes-cache` meets: the predicate cannot see a write (contract clause unobserved)

Mechanism, from the frozen counter's own bytes:

* `TRACE_SET = "trace=execve,execveat,socket,socketpair,connect"` (line 141) and the trip regex
  `^(execve|execveat|socket|socketpair|connect)\(` (line 339). `openat`/`creat`/`write`/`unlink`/`rename` are
  outside the traced set, so a write is not a trip.
* For a **tool** run `mode = "--ro-bind"` (line 279): the case root and `<root>/.rw` are mounted read-only,
  so the resolver's `save_cache` fails with `EROFS`. A tool that swallows the `OSError` is byte-indistinguishable
  from one that never writes — the counter takes no fingerprint of the tool tree.
* The docstring's clause‑i sentence "the tool writes nothing, so a tool that performs the resolver's save fails
  here" (line 85) is therefore **false** for a swallowing tool. Measured:

```
$ # writable cache dir: the write is real (reference writes nothing, the mutant writes 56 B)
writes-cache mutant, writable $XDG_CACHE_HOME : mut rc=0, cache 0 entries -> 1 entry (56 B)
                                                 "00000000000000000000000000000000\nfoot\n^^END_OF_EXEC_USEP"
frozen reference,   same tree                 : ref rc=0, cache entries after: 0

$ # cache dir mode 555 (the EROFS the sandbox's read-only .rw produces)
writes-cache mutant, mode 555                 : alpha.desktop / mut rc=0, cache after: empty
frozen reference,   mode 555                  : alpha.desktop / ref rc=0
```

(`write-demo.txt`; the stdout and exit status are identical in the 555 case, which is exactly the sandbox
shape.) The registration is explicit that this must not happen: "`w1/ExecControlsC1`'s 20 controls must be
re-scored against this frozen merged fixture set: … `writes-cache` … every skip/mutant must miss, and a control
that meets triggers a fixture/counter repair before freeze." W1's own report already predicted this hole
(its F4) but could not score it: the draft column for `writes-cache` is marked `cut`.

The same blindness covers the sandbox's writable `/tmp` (`--tmpfs /tmp` is in the mount list, line 278): a tool
that writes *there* is equally invisible. So the repair cannot be "make `.rw` writable and check it is empty"
alone.

### B2 — `content-cold2` meets: `--print-content` on a live warm hit is not scored

The frozen warm file contains `--print-content` in exactly four fixtures: `v2-ws-04-content-mut` (`WARM-SAME`,
inert: the warm answer equals the cold one), and three hits whose cached path is **gone** —
`L1-01-gone-path-content`, `L1-02-gone-path-id-content`, `L1-03-gone-path-content-cmd` — which score the
`shcat` failure → rc 1. Every `WARM-DIFFERS` fixture uses `--print-cmd`, `--print-id`, `--print-path` or
`--test`. There is **no** warm fixture in which a hit's cached entry path is live *and* differs from the cold
selection *and* content is printed — yet that is precisely the "stale-but-valid cache starts/prints a different
thing than a cold run would" case the C1 claim is about.

That gap is exploitable with one branch, and the deviation is real, not cosmetic. Receipt
`content-diff-cold2.txt` (tree: two entries `alpha`/`bravo`; primed cache holds `alpha`; the list file is
edited `alpha.desktop` → `bravo.desktop`, same byte length, mtimes re-pinned to 1600000000, so `gen_hash` is
unchanged — the pin itself reports `cache is actual`):

```
pin  --print-content (warm, "D: cache is actual") : Exec=alpha
pin  --print-content XTE_CACHE_ENABLED=false       : Exec=bravo      (what a cold run answers)
frozen reference tool --print-content              : Exec=alpha      (agrees with the pin)
content-cold2          --print-content             : Exec=bravo      (disagrees with the pin)
```

`content-cold2` scores `warm=204/204 explained=394/394` and `TARGET_MET`. Note the neighbouring aggressive
variant `content-cold` (content always from the cold selection, also for a dead cached path) **is** caught —
by the three `L1-0x-gone-path-content` fixtures on clause `w` (`201/204`). So the set tests the cached-path
*absent* branch of content and never the *live cached path ≠ cold entry* branch.

## 6. Clauses that held in this attack

* **a** — `tool=present` with the blob at `HEAD:tools/mado-terminal.py` in every run.
* **s** — selftest line is `MADO_TERMINAL_SELFTEST: N/N passed` (`69/69` for the reference); the two mutants
  whose own selftests cover the rule fail here (`67/69`, `68/69`). Clause `s` is self-authored and is
  independent evidence for nothing; it caught nothing the predicate's own fixtures did not also catch.
* **f** — `cold=190/190` for every candidate including the two false passes: the round-47 harm watch still
  holds and is unchanged by this round's warm work.
* **w** — real teeth for `trust-any` (14 fixtures) and for the aggressive content variant (3); the state
  premise (`check_premise` → `setup error`) did not fire in any run, i.e. no fixture's recorded state or
  `WARM-DIFFERS`/`WARM-SAME` premise drifted on this host.
* **x** — the strongest clause in the set: it alone caught `explain-cmd-const` (347), and it is the only
  independent catcher of `no-line-limit` (2).
* **g** — `230/230` for every candidate: the generated nonce cases are correctly kind-partitioned and did not
  catch any of these deviations (as expected — the mutants are not in the generated distribution).
* **r** — clean on every non-process candidate, and `trips=1262` for `delegate-ls`: the trace correctly
  attributes an `execve("/oracle/bin/ls", …)` per hash computation.
* **i** — the mount set behaved as declared (no fixture byte was reachable from a tool run; the two false
  passes do not depend on reading anything outside the case tree). Not independently attacked here beyond the
  write case in B1.

## 7. Repairs the L1 needs before data (I did not implement them)

1. **Close B1 in clause r/i**: fingerprint the tool tree before and after every tool run (path, mode, size,
   mtime, nlink; one `os.walk`) and make any difference a failure of that run — this catches the write even
   though the mount refuses it, and it also covers `/tmp` if the fingerprint is extended to the sandbox tmpfs,
   or trace `openat`/`creat`/`unlink`/`renameat` and filter to write-intent flags. Until then the frozen
   predicate does not test "the tool writes nothing", which the registration's contract and residuals both
   state.
2. **Close B2 in clause w**: add warm fixtures with `args` = `["--print-content"]` (and
   `["--print-id","--print-content"]`) on a `WARM-DIFFERS` hit whose cached entry path is **live** and differs
   from the cold selection — the same-size list/order edit already used by the set, plus a live cached path.
   `content-diff-cold2.txt` is the recipe; the third tree (cold twin) must show the differing answer or the
   premise fires.
3. **Fix the control table** (registration §C1 Controls): drop `f` as a catcher for `trust-any` and
   `no-line-limit`; record `s+w+x` and `s+x` respectively; and record that `no-line-limit` passes `w`
   entirely (`warm=204/204`), so the 50-line rule's independent teeth are the two `state` fixtures in `x`.

## 8. Risks and limits of this seat's evidence

* My `writes-cache` mutant writes a placeholder two-field cache with the terminator, not the resolver's full
  ten-field save; the contract violation ("the tool writes the cache") is identical, and any write is invisible
  to the frozen predicate — but a reader should not read the placeholder as w1's fuller mutant. The measurement
  that matters is `verdict=TARGET_MET` for a writing tool.
* `content-cold2` is a wrong tool only on inputs the frozen set does not contain; its wrongness is shown
  against the pin on a hand-built tree (`content-diff-cold2.txt`), not against a frozen fixture.
* Single host, single nonce (4848) for all eight counter runs; each full run took 3–7 min under 3–5 concurrent
  probes.
  The `ls`/coreutils version dependence of clause `w` is the registration's declared residual and was not
  re-attacked.
* One structural deviation in the harness is documented in §2 (minimal fixture repo instead of a lane clone)
  because the lane index (2 771 712 B) exceeds the mandated 1 MiB per-file guard. The freeze blobs were
  re-hashed into the fixture repo, so the counter read the same bytes.
