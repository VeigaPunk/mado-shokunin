### Description

When commenting one of the 2 lines the other works fine but both don't.

### How to reproduce

Just use this in `~/.config/hypr/hyprland.conf`. and try changing the layout and using CapsLk as Esc.
```
input{
  kb_layout = us,ara
  kb_variant = ,
  kb_options = grp:alt_shift_toggle
  kb_options = caps:swapescape

  follow_mouse = 1
  accel_profile = flat
  scroll_factor = 0.8
  
  touchpad {
    natural_scroll = yes
  }
}
```
