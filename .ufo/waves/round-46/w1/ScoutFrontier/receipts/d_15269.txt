I was running
input {
kb_layout = us
kb_variant = gallium
kb_model =
# kb_options = caps:swapescape
kb_rules =
}
where I've previously updated the xkb file to include the custom layout as another us variant. All fine until the last update & now I get
Runtime Error - Invalid keyboard layout passed. (rules: , model: , variant: gallium, options: , layout: us )
Also... it switched to qwerty by default. I managed to get my layout working after adding the path to the file containing the new layout.
New config:
input {
kb_layout = us
kb_variant = gallium
kb_model =
# kb_options = caps:swapescape
kb_rules =
kb_file = /usr/share/xkeyboard-config-2/symbols/us
}
the custom layout works, but I can't get rid of the error msg. I don't want to just suppress errors, I don't understand why hyprland still thinks this layout/variant doesn't exists.
Also all the keybindings follow the qwerty layout instead of the gallium one... but that's not a big deal.

I'm guessing you had to re-add gallium to the symbols file after the update too cause xkeyboard-config also just updated, and that's exactly why you don't edit system files, your changes get overwritten all the time. To do it properly put only the variant in ~/.config/xkb/symbols/us, remove kb_file from config, restart, see if that works.
