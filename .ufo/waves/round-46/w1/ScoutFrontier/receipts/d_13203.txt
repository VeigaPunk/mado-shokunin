Issue
Previously I was setting mouse input sensitivity in input:sensitivity, but that also changes touchpad sensitivity, that I do not want to change.
Then I started to use "per-device" config. But then, some time ago, I found issue, that device name changes frequently when I switch from wired to wireless connection.
As I did not found way of searching devices using glob pattern, I made configs for each version.
Now it looks like this:
// .config/hypr/hyprland.conf
device {
name = razer-deathadder-v2-pro
sensitivity = -0.6
}
device {
name = razer-razer-deathadder-v2-pro
sensitivity = -0.6
}
device {
name = razer-razer-deathadder-v2-pro-1
sensitivity = -0.6
}
device {
name = razer-deathadder-v2-pro-2
sensitivity = -0.6
}
device {
name = razer-razer-deathadder-v2-pro-4
sensitivity = -0.6
}
device {
name = razer-deathadder-v2-pro-1
sensitivity = -0.6
}
device {
name = razer-deathadder-v2-pro-3
sensitivity = -0.6
}
Today device is named differently again:
// hyprctl devices
Mouse at 562a1116bc80:
razer
default speed: 0.00000
scroll factor: -1.00
Mouse at 562a111a9130:
razer-2
default speed: 0.00000
scroll factor: -1.00
Possible solutions
Implement separate sensitivity properties for mouse and touchpad. input:sensitivity and input:touchpad:sensitivity. Could also require adding input:tablet:sensitivity
Implement glob pattern for per-device configs
Other way fixing issue of same device name getting change all the time
