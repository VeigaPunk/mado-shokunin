Bug

### Description

Following [this article ](https://wiki.hyprland.org/Configuring/Uncommon-tips--tricks/#switchable-keyboard-layouts) from the wiki. I'm trying to add a spanish keyboard layout as secondary (is just for switch and use a few special characters)

_The easiest way to accomplish this is to set this using XKB settings, for example:_
```
input {
    kb_layout = us,pl
    kb_options = grp:alt_shift_toggle
}
```

This works as expected, using the toggle bind, layout is switched. The issue emerges when I reboot the machine, secondary layout is removed from the file, so I need to edit it each time I turn on my machine. 

This happens only with `kb_layout` var,  all the other edits I made in my conf file remains as expected.

My code before reboot:
```
input {
kb_layout = us,es
kb_variant =
kb_model =
kb_options = grp:win_space_toggle
kb_rules =
numlock_by_default= true
follow_mouse = 1
touchpad {
    natural_scroll = true
    tap-to-click = true
    disable_while_typing = true
}


    sensitivity = 0 # -1.0 - 1.0, 0 means no modification.
}
```

My code After reboot:

```
input {
kb_layout = us
# ....
```


### How to reproduce

Edit: `~/.config/hypr/hyprland.conf` and add any secondary layout
```
input {
kb_layout = us,es
```
then reboot.
