Good morning.
Since my laptop's integrated keyboard has a different layout than the external one I sometimes attach via USB, I tried to set the kb_layout parameter inside a section named after what hyperctl devices suggested me:
device:AT Translated Set 2 keyboard {
kb_layout=it
}
However, this setting seem to be completely ignored by Hyprland, which loads only the layout specified inside the global input section.
I tried to replace the spaces in the keyboard's name with hyphens and underscores, but it seems that the correct layout is never actually loaded, so I'm writing here in search of some help.
Thank you in advance to anyone who can help me figure out what am I doing wrong to get this behavior.
