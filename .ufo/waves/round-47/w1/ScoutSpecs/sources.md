## 4. Spec versus script: where the judge (the real script) departs from the specs

The C1 judge is the pinned script, so every row here is a place the tool must follow the script, not the spec. Each is observed by running `/usr/bin/xdg-terminal-exec` (sha256 89f2be9a...) in print mode only, one throwaway tree per case, `XDG_CACHE_HOME` inside the case, `LC_ALL=C`; cases and outputs are in `probes.tsv`, the driver is `probes.py` (run as `python3 probes.py <scratch dir>`). Outputs use `$ROOT` for the case root.

| probe | spec says | script does (observed) |
|---|---|---|
| P01-P03 | Type: unknown type should be ignored (Q21) | no Type check: entry with no Type, Type=Link and Type=Bogus are all selected (rc 0). `grep -in type` over the script finds only comments and `find -type f` (xdgte-xdg-terminal-exec:766). The draft explain text "wrong Type" has no script counterpart |
| P04-P05 | NoDisplay is a menu-display key (Q22); not part of the resolver's rule list | NoDisplay=true entries are selected from the explicit list and from the fallback scan (rc 0) |
| P06-P08 | boolean is exactly `true` or `false` (Q11) | Hidden rejects only the string `true` (script:938-943); Hidden=TRUE and Hidden=1 are selected, Hidden=true gives rc 1 and the stderr "No valid terminal entry was found in:" plus the two applications dirs |
| P09 | subdir -> '-' (Q01, Q37) | matches: applications/sub/foo.desktop is ID sub-foo.desktop (awk gsub at script:797) |
| P10 | spaces around '=' ignored (Q07) | `Categories = TerminalEmulator` and `Exec = fooexe` are accepted (key matched by glob 'Categories'*=*, script:816) |
| P11 | relative XDG dirs should be ignored (Q46) | relative `XDG_DATA_HOME=rel` is used: the entry under `$PWD/rel/applications` is selected |
| P12-P14 | application ID elements should not start with a digit (Q05) | find filter accepts a leading digit (`1foo.desktop` selected); rejects a space in the name and a leading dot (script:773: first char [a-zA-Z0-9_], no char outside [a-zA-Z0-9_./-]) |
| P15-P16 | explicit entries skip *ShowIn, fallback enforces it (Q58, Q59) | matches: OnlyShowIn=GNOME on Hyprland is rc 1 in fallback and selected when listed |

| P19 | [Desktop Entry] first (Q10) | keys before the group header are not read as Exec/Categories: entry rejected (rc 1) |
| P20 | data home outranks data dirs (Q48) | matches: print-id/path/cmd give the $XDG_DATA_HOME entry and its Exec |
| P21 | not specified | a data dir written `.../share//` is not normalised: printed path is `$ROOT/usr/share//applications/foo.desktop` (script strips one trailing `/` only: `${xte__dir%/}`, script:168) |

Additional observations from reading the pinned script (not probed): the key dispatch uses prefix globs (`'Hidden'*=*`, `'Categories'*=*`, `'Actions'*=*`, script:816-938), so a key such as `HiddenX=true` or `Categoriesfoo=` would take the same branch [INFERENCE, unprobed]. The unsuccessful run's message goes to stderr, outside the stdout+exit contract. `bats` upstream tests are listed at S330 as seed cases.
