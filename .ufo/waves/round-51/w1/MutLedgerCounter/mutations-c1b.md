## Fixture/control interpretation

The five frozen controls in claims.md are runtime negative controls, not sufficient by themselves to kill the mutations above. In particular, omitting one row (a) does not establish extension-neutral globs, recursive boundaries, or path-identity handling; a missing-basename pointer (b) does not establish case sensitivity or that file contents rather than pointer spelling are examined; and absent ledger at base (e) does not prove use of `--rev` instead of live checkout. Selftest must use an isolated git fixture with distinguishable commits and assert population set, verdict/counters, and exit code for each arm. A live worktree mutation must not affect a historical invocation.

No counter implementation or selftest was present in the inspected round-51 seat/draft paths at probe time; therefore mutant outcomes are design-level coverage findings, not executed kill results. No files outside the assigned seat were changed.
