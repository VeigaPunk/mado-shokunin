#### [](https://blog.csdn.net/2301_76324845/article/details/149787804)1.设置双指滑动键盘上的touchpad去scroll一个页面

打开【~/.config/hypr/**userprefs.conf**】，添加或更改

```bash
input {    touchpad {        natural_scroll = yes  //no和yes是两种方式，自己试        scroll_factor = 0.2   //更改速度    }}
```

领2年VIP bash

设置几根手指滑动工作区也在这里面：

```bash
gestures {    workspace_swipe = true    workspace_swipe_fingers = 3}
```

领2年VIP bash

注意：vim如果要输入指令（比如:wq）要在英文输入法下，要不然你连：都输不了

#### [](https://blog.csdn.net/2301_76324845/article/details/149787804)2.改变窗口的不透明度

step1：找到要更改的应用程序的名称，先打开此应用程序，再在终端中输入

```bash
hyprctl clients
```

领2年VIP bash

找到类名，如class: code

step2：更改透明度

打开【~/.config/hypr/**windowrules.conf**】，找到代码

```bash
windowrule = opacity 0.80 $& 0.80 $& 1,class:^([Cc]ode)$
```

领2年VIP bash

分析：（1）opacity 0.80 $& 0.80 $& 1

对应opacity [active_alpha] $& [inactive_alpha] $& [fade_duration]

分别为【窗口激活时透明度】【非激活时透明度】【渐变持续帧数:`1`或`0`代表是否淡入淡出）】

#### [](https://blog.csdn.net/2301_76324845/article/details/149787804)3.配置vim(添加/删除行号，更改tab键的位数)

##### 3.1暂时改变行号：

先进入vim模式，按Esc进入命令模式

（1）在vim中添加/删除 绝对行号

添加：输入 :set number 或 :set nu 删除：输入 :set nonumber 或 :set nonu

（2）在vim中添加/删除 相对行号

添加：输入 :set relativenumber 或 :set rnu 删除：输入 :set nonrelativeumber 或 :set nornu

##### 3.2永久改变：

先说结论：

```bash
vim ~/.config/vim/vimrc
```

领2年VIP bash

在这个文件最后添加：

```bash
set norelativenumber    " 删除相对行号
```

领2年VIP bash

两段代码讲明了vim的配置加载逻辑，如果配置升级，那么/usr/share/vim/vimfiles/archlinux.vim将会被新的默认配置覆盖,因此不要修改它。

继续阅读**/etc/vimrc**，看到 runtime! archlinux.vim,这里就是在加载vim的默认配置，我们如果要更改某些配置，在这条语句的**下方**空白 处添加语句：

```bash
set number              " 显示绝对行号set norelativenumber    " 删除相对行号set tabstop=4           " Tab 显示为 4 个空格
```

领2年VIP bash

注意！！由于/etc/vimrc是只读文件，因此要sudo vim/etc/vimrc 打开文件

完成之后并不会立即改变，需要用vim随意打开一个文件之后 按Esc进入命令模式，输入

**:source /etc/vimrc** 命令才可以应用

但是我们发现，当关闭vim后重新进入，行号又变成了默认状态，因此我们可以在vim中输入命令：

```bash
:scriptnames
```

领2年VIP bash

领2年VIP bash
