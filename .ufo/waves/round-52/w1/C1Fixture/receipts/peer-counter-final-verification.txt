The check is a hardcoded total, which is the lane's own idiom (see
quality/check-tool-ledger.py's SELFTEST_CHECKS = 50): a case that silently disappears
must fail the run rather than shrink it. The constant is simply stale relative to the
cases that were just added. Reproduced twice, deterministically.

This is reported as an observation about the peer's in-flight bytes, not as a judgement
of the final counter: the file is at 715 lines and was being written at 10:33 while
this seat read it. The fix is a one-token change (34 -> 39) in the same file.

exit=0" was true of the PREVIOUS bytes (39e3d1f4..., where the count was still 34) and
is no longer true of the current bytes. This seat did not re-run the selftest on
