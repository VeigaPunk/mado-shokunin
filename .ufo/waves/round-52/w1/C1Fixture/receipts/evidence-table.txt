D. NO SOURCE-TREE WRITES
----------------------------------------------------------------------
Measured, not assumed.

  * The lane is only ever read. The harness clones it with
    `git clone -q --shared --no-checkout <lane> <scratch>/fixture-*`; the fixture's
    alternates file points at the lane's object store for reading.
  * The lane's object store is unchanged: 10493 files before and after the run.
    The fixture's own `hash-object -w` / `commit-tree` writes land in the fixture's
    object store, not the lane's.
  * Before and after the cases the harness takes a git-native integrity snapshot of
    the lane working tree: the index's blob ids for every tracked path, the unstaged
    diff path set, the staged diff path set, and the untracked path set outside the
    round's wave directory. All four hashes are identical before and after:
    lane_unchanged=True.
  * The fixture working tree is empty by construction (a --no-checkout clone), so any
    file left there is a write. fixture_worktree_residue was empty for all five cases.
  * The counter runs with HOME, TMPDIR and the XDG_* homes redirected under the case's
    own --work directory.
  * --work is refused when it resolves to /tmp, /var/tmp or /dev/shm
    (setup error, exit 2). Verified: `--work /tmp` -> exit 2,
    "C1_FIXTURE_HARNESS: setup=error detail=--work must not be a system temp root: /tmp".
  * A missing --counter is also a setup error, exit 2.
