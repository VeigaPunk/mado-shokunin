----------------------------------------------------------------------
E. THE F3 CEILING — INDEPENDENTLY CONFIRMED, AND IT IS WIDER THAN FLAGGED
----------------------------------------------------------------------
The peer flagged that "a description that copies a genuine two-word phrase out of the
instrument's own bytes still passes". This seat reproduced that independently, and found
a second, adjacent gap the peer did not flag.

The generic_desc clause (counter source, the `else` branch after the length test) is:
  - the description must have >= 5 words (MIN_DESC_WORDS = 5);
  - it must share a two-word phrase ("bigram") with the instrument's own bytes;
  - and at least one such bound phrase must carry a word the instrument's PATH does not
    contribute ("only-path-name-phrase" otherwise).

E1 — a semantically EMPTY description carrying a real two-word phrase from the
instrument's own bytes PASSES:

  row: | `quality/counters/c1-r49-keysym.py` | usr bin and nothing else at all here okay. |
        `SCORECARD.md:2736` |
  -> C1_R52: population=82 ledger_rows=82 uncovered=0 dup=0 dangling=0 bad_pointer=0
             self_pointer=0 generic_desc=0 verdict=TARGET_MET
     exit=0

  "usr bin" is a genuine two-word phrase occurring in the instrument's own bytes at the
  base revision. The description says nothing about the instrument's function, yet the
  counter accepts it. The clause measures phrase OVERLAP, not functional content.

E2 — a description made ONLY of the instrument's own path words also PASSES, i.e. the
"only-path-name-phrase" guard did not fire:

  row: | `quality/counters/c1-r49-keysym.py` | c1 r49 tools mado keysym and nothing more
        here okay. | `SCORECARD.md:2736` |
  -> C1_R52: population=82 ledger_rows=82 uncovered=0 dup=0 dangling=0 bad_pointer=0
             self_pointer=0 generic_desc=0 verdict=TARGET_MET
     exit=0

  The path is quality/counters/c1-r49-keysym.py, whose path words are {c1, r49, keysym,
  counters, quality}. The bound bigram "c1 r49" is made only of path words and should
  have triggered "only-path-name-phrase" -- but the description ALSO contains the bigram
  "tools mado" (from the word pair "tools mado" occurring in the body), whose words are
  not path words, so the clause's "any(...)" is satisfied by that OTHER bigram. The
  guard is per-phrase-ANY, not per-description, so a single unrelated bound bigram
  anywhere in a long description launders the whole row.

Both gaps are properties of the measurement, not of the harness: they are in the
counter's clause, which this seat does not own. Recorded here so the wave-2 critic
attacks them against the item they belong to, and so the L1 knows the C1 claim's
"instrument-specific functional context" check is a phrase-overlap check, not an
entailment check. The frozen claim already limits itself to "bounded accountability
checks, not prose entailment", so this does not contradict the claim as frozen -- but
the ceiling is wider than one phrase-copy.

Counter-check that the clause is not simply broken: the genuine production description
for that same row still passes, and the green case shows all 82 production rows carry
