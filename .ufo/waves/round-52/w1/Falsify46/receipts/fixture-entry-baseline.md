## The chain

1. **P01 (S370).** Proposition P01 reads: `sendkeystate` takes exactly four comma-separated fields and rejects any other count before touching state. The pinned bytes say: `CVarList2 ARGS(args, 4); if (ARGS.size() != 4) return {.success = false, .error = "sendkeystate: invalid args"};` (Hyprland-legacy-DispatcherTranslator.cpp:591-594).
2. **P02 (S370).** Proposition P02 reads: The state field is a closed three-value set - `down`, `repeat`, `up` - and any other token is refused. The pinned bytes say: `if (STATE != "down" && STATE != "repeat" && STATE != "up")` (Hyprland-legacy-DispatcherTranslator.cpp:597-598).
3. **P03 (S370).** Proposition P03 reads: `down` and `repeat` are both a press (keyState 1 and 2); `up` is the default keyState 0. The pinned bytes say: `if (STATE == "down") keyState = 1; else if (STATE == "repeat") keyState = 2;` (Hyprland-legacy-DispatcherTranslator.cpp:601-604).
4. **P04 (S370).** Proposition P04 reads: `repeat` runs the delegate a second time, and only when the first call reported success. The pinned bytes say: `auto result = sendshortcut(modifiedArgs); if (keyState == 2 && result.success) result = sendshortcut(modifiedArgs);` (Hyprland-legacy-DispatcherTranslator.cpp:619-622).
5. **P05 (S370).** Proposition P05 reads: `sendkeystate` does not resolve anything itself: it rebuilds a three-field tail without the state field and delegates to `sendshortcut`. The pinned bytes say: `std::string modifiedArgs = std::string(ARGS[0]) + "," + std::string(ARGS[1]) + "," + std::string(ARGS[3]);` (Hyprland-legacy-DispatcherTranslator.cpp:607).
6. **P06 (S370).** Proposition P06 reads: `sendshortcut` itself requires exactly three fields (mods, key, window). The pinned bytes say: `CVarList2 ARGS(args, 3); if (ARGS.size() != 3) return {.success = false, .error = "sendshortcut: invalid args"};` (Hyprland-legacy-DispatcherTranslator.cpp:531-535).
7. **P07 (S373).** Proposition P07 reads: The `sendshortcut` path inherits the bind parser's uppercase-substring modifier reading, so an unrecognised word is silently mask 0 while any word containing a known name sets its bit. The pinned bytes say: `std::ranges::transform(mods, mods.begin(), ::toupper); if (mods.contains("SHIFT")) modMask |= HL_MODIFIER_SHIFT;` (Hyprland-KeybindManager.cpp:223-225).
8. **P08 (S370).** Proposition P08 reads: The key field has a numeric branch: a plain number greater than 9 is a keycode, and `code:N` is the same number in the same space. The pinned bytes say: `if (isNumber(KEY) && std::stoi(KEY) > 9) keycode = std::stoi(KEY); else if (KEY.starts_with("code:") && isNumber(KEY.substr(5))) keycode = std::stoi(KEY.substr(5));` (Hyprland-legacy-DispatcherTranslator.cpp:540-543).
9. **P09 (S370).** Proposition P09 reads: The `mouse:` branch accepts only numbers at or above 272 and rejects the rest. The pinned bytes say: `if (KEY.starts_with("mouse:") && isNumber(KEY.substr(6))) { keycode = std::stoi(KEY.substr(6)); if (keycode < 272) return {.success = false, .error = "sendshortcut: invalid mouse button"};` (Hyprland-legacy-DispatcherTranslator.cpp:544-547).
10. **P10 (S370).** Proposition P10 reads: The remaining key names are resolved by scanning the seat keyboard's whole keycode range against the current xkb state. The pinned bytes say: `for (xkb_keycode_t kc = keycode_min; kc <= keycode_max; ++kc) { xkb_keysym_t sym = xkb_state_key_get_one_sym(ks, kc);` (Hyprland-legacy-DispatcherTranslator.cpp:565-566).
11. **P11 (S370).** Proposition P11 reads: The keysym result is cached per keyboard pointer and raw key spelling, not per keysym. The pinned bytes say: `const auto KEYPAIRSTRING = std::format("{}{}", rc<uintptr_t>(KB.get()), KEY);` (Hyprland-legacy-DispatcherTranslator.cpp:557).
12. **P12 (S370).** Proposition P12 reads: An empty third field means the focused surface; a non-empty selector that resolves to nothing is an error. The pinned bytes say: `const std::string regexp = std::string(ARGS[2]); PHLWINDOW PWINDOW = regexp.empty() ? nullptr : Desktop::viewState()->query().selector(regexp).runWindow();` (Hyprland-legacy-DispatcherTranslator.cpp:582-586).
13. **P13 (S371).** Proposition P13 reads: The synthetic event carries the timestamp of the last real input event and the keyboard keycode minus 8; the modifier mask is asserted before delivery and cleared to 0 after. The pinned bytes say: `g_pSeatManager->sendKeyboardKey(S.m_timeLastMs, key - 8, WL_KEYBOARD_KEY_STATE_PRESSED);` (Hyprland-ConfigActions.cpp:1558-1558).
14. **P14 (S372).** Proposition P14 reads: The shared state field is the last key/mouse event's timestamp, defaulting to 0. The pinned bytes say: `uint32_t m_timeLastMs = 0; // timestamp of last key/mouse event` (Hyprland-ConfigActions.hpp:117-117).
15. **P15 (S370).** Proposition P15 reads: `sendkeystate` restores the previous press field after it delegates, so a dispatch does not leave its state behind. The pinned bytes say: `const int oldPassPressed = Config::Actions::state()->m_passPressed;` (Hyprland-legacy-DispatcherTranslator.cpp:612-612).
16. **P16 (S371).** Proposition P16 reads: A written selector that resolves nothing and an empty selector end in different delivery paths: empty passes nullptr and the focus switch is skipped. The pinned bytes say: `if (!window) return {};` (Hyprland-ConfigActions.cpp:1578-1579).
17. **P17 (S370).** Proposition P17 reads: A keysym the scan cannot find fails with `key not found` inside the scan, distinct from the later generic `invalid key` guard. The pinned bytes say: `return {.success = false, .error = "sendshortcut: key not found"};` (Hyprland-legacy-DispatcherTranslator.cpp:574).
