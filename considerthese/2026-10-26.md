## Top 3 lessons / gains

### 1. Three new read-only tools that answer real questions about João's running desktop (rounds 39–43)

`mado-options.py` (r39, `--live` in r40), `mado-globals.py` (r41) and `mado-geometry.py` (r43) each answer one concrete "why does my desktop do this" question: which file actually sets this option and does the running compositor agree; which Wayland protocols the session advertises; and whether a floating window's size rule (here gkeep's 420×500) actually reaches the window. Each was re-run on the live host by a non-author closure and reproduced its receipt. With `mado-eventq.py` from round 37, the lane now has four live-state tools instead of only config-byte checkers. This is the clearest capability gain since the lane started.

### 2. Reported size is not requested size: the geometry chain was traced end to end (round 43)

The lane refused two staged entries (`gkeep-size-rule-application-r10.md`, `gkeep-observation-route-r11.md`) and admitted a re-grounded third. The traced chain: rule value → `windowGeometry` → target box → `m_realSize` → the `size` field in `hyprctl clients -j`, which reports `GEOMETRIC_GOAL` (HyprCtl.cpp `:427-428`), not what the client asked for; the r10 quote came from the X11 branch that feeds `sendWindowSize`. Rule matching is a full RE2 match with a `negative:` prefix (RegexMatchEngine.cpp `:7-8`, `:16`). The closure re-fetched the upstream files at v0.56.2 (`efb5099`) and found them byte-identical to the pins. This is the domain lesson to reuse: before comparing a rule to an observed size, confirm which stage of the pipeline the observation reads.

### 3. Freeze discipline now has teeth, and the lane says out loud when its own counters are weak (rounds 38–43)

Round 38's calibration claim failed because the control manifest was rewritten after the freeze (`b6c1d31`); the closure ruled 18/19 for the frozen pair and required re-registration, which round 39 did before any data. Round 39 then caught a registration that named a counter file missing from the freeze commit, and added QUALITY criterion 64 so that check runs at freeze time. From round 40 on, every round re-registered v2 predicates before data when wave 1 showed v1 was gameable, and declared the remaining weakness (r41: 5 of 11 cheats reach TARGET_MET; r43: C2 v2 admits 14/14 do-nothing controls). The closures responded by reading content claim by claim instead of trusting TARGET_MET. The lesson: a passing counter is weak evidence until someone reads the entry, and the lane now records that instead of hiding it.
