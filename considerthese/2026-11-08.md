### 2. The MIME chain gained the text-magic step and the path's GIO content type (rounds 96–97)

Yesterday's reflection stopped at `mado-mimesniff.py` (bytes + name) and `mado-mimeglob.py` (filename only). This window adds the two missing steps before a file manager's "type" column and before launch:

- Round 96 landed `tools/mado-mimetext.py` (entry `corpus/knowledge/mime-textdb-magic-r96.md`): the text `mime/magic` database the r95 tool refuses in text mode. Per `LOG.md`, C1 at `5dd921b3` scored 284/284 frozen cases (16/16 classes), 268/268 seeded fresh inputs, 9822/9822 host pairs over the round-95 4911-file list against the host's cache-free text database, and 84/84 counted mutants (`.ufo/waves/round-96/receipts/c1-measured-r96.txt`). Separability: C1 `TARGET_MET` at the C2 tip. An append-only correction (commit `0caf2465`, restated as **M97-1**) moved the cache-version claim from "bytes 4..7" to offsets 0..3 (BE u16 major, then minor) to match the frozen counter and the refusal fixtures.
- Round 97 landed `tools/mado-filetype.py` (entry `corpus/knowledge/gio-content-type-file-r97.md`): the content type GIO 2.90.1 reports for a **path** (`standard::content-type` / `standard::fast-content-type`). Per `LOG.md`, C1 at `4541d94b` scored 157/157 frozen cases (15 classes), 101/101 counted mutants, 140/140 fresh paths, and 6194/6194 frozen host labels (0 mismatches, 0 drift) (`.ufo/waves/round-97/receipts/c1-measured-r97.txt`). **M97-2** is the depth gain: the first contract said any un-stat'able path (missing, or a symlink loop) prints `ERROR stat` and exits 2. The library is narrower — `lstat` failing with `EACCES` is tolerated and answered from the name as `application/octet-stream` exit 0; a symlink loop is answered `inode/symlink` exit 0; only other errnos (e.g. `ENOENT`, `ENOTDIR`) refuse. So a name/type mismatch in a file manager's type column can be expected GIO behaviour, not a bug in the database (`round-97.md` Cross-domain evidence). **M97-3**: the host-list seat walked `~/.config` and would have fed credential-shaped paths (`gh/hosts.yml`, `anthropic/credentials`, and others named in the lesson) into a counter that sniffs bytes; the sanitiser dropped 95 such paths and the frozen list is the 6,194-path stable system subset, with the counter refusing any remaining credential-shaped path fail-closed.

Together with rounds 91–95, the lane now has measured tools for bytes+name → text-magic type → path type → default application → `xdg-open`'s resolver → launch argv → spawn environment → unset-PATH default. Nobody yet scores that chain end to end against a real `gio launch` / `xdg-open` dry run (yesterday's proposal 2, still open).
